# Keshav Banking System 🏦

## 📖 Project Overview
The Keshav Banking System is a C++ based console application designed to manage basic banking operations. This project demonstrates core programming concepts including data structures, conditional logic, and user input handling to simulate a real-world banking environment.

## ✨ Key Features
* **Account Creation:** Setup new accounts with unique details.
* **Secure Transactions:** Perform deposits and withdrawals with balance validation.
* **Balance Inquiry:** Check current account standing in real-time.
* **User-Friendly Interface:** Clear console-based menus for easy navigation.
